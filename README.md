# Facturas CSharp

Aplicación de escritorio para la gestión de facturación, desarrollada en **C# y Windows Forms**.

El proyecto procede de una aplicación de facturación desarrollada originalmente en **VB.NET** y posteriormente convertida a C#, conservando la funcionalidad de la aplicación original.

## Funcionalidades

La aplicación incluye, entre otras, funcionalidades para:

- Gestión de clientes y proveedores.
- Gestión de materiales.
- Gestión de albaranes.
- Facturas de venta y de compra.
- Facturas de abono.
- Aplicación de descuentos e IVA.
- Consultas y listados de compras y ventas.
- Generación de informes y facturas mediante Crystal Reports.

## Tecnologías

- C#
- .NET Framework
- Windows Forms
- SQL Server
- ADO / ADO.NET
- Crystal Reports
- Visual Studio

## Base de datos

La aplicación utiliza una base de datos SQL Server denominada `Facturas`.

Las credenciales utilizadas en el entorno original de desarrollo han sido eliminadas del repositorio. Las cadenas de conexión contienen `CHANGE_ME` como marcador y deben configurarse con las credenciales correspondientes antes de ejecutar la aplicación.
